# 間違えやすい書き方

「書いても読み込みでエラーにならないのに、思った通りに鳴らない」書き方の一覧です。曲が思い通りに鳴らないときは、まずここを確認してください。

| 書き方 | 実際の動作 | 正しい書き方 |
|---|---|---|
| `t120` | 読み込まれますが、**何も起きません** (テンポは変わりません) | 曲全体は `; tempo=`、曲の途中は `[TB n]` または `[BPM n]` |
| `>` / `<` (単独) | 読み飛ばされます | `o>` / `o<` |
| `c4` / `d8.` | 音符の後ろの音長は、ありません | `L4` を前に書く、または `l(48)` |
| `l4` (小文字 + 数字) | 音長として成立しません | `L4` (大文字)、または `l(48)` |
| `e3` / `d12` | 音符ではなく、エンベロープ 3 (`E3`)・デチューン 12 (`D12`) として読まれます | 音符は `e~0` `d~0` のように `~` を付ける |
| `[RK b]` のあとに `r` | 休符ではリズムは鳴りません | `[RK b] o2 c` のように、音符を置く ([リズム](commands/rhythm.md)) |
| `role=PCM_0` | PCM のロールは `role=` で指定できません | `CHP1:` と書く ([PCM](commands/pcm.md)) |
| `[RZ]` で `0E` を書く | 意図的にエラーになります | リズムは `[RK]` を使う |
| `[FE 0B]`〜`[FE 0F]` | 受け付けません | `[FE 00]`〜`[FE 0A]` を使う |
| `[GATE-RESET]` / `[GATE_RESET]` | 読み込まれますが、何も起きません | — |
| 数値の足りない `opna_patch_NN` / `opm_patch_NN` | 行ごと、黙って無視されます | 38 個 (OPNA) / 46 個 (OPM) をそろえる |
| `; chip=opna` で `hw=` を書く | 無視されます | `hw=` は `; chip=all` のときだけ有効 |
| `p1` を OPLL / OPNA で使う | 受け付けますが、音は変わりません | パンは OPM と PCM のみ有効 ([音量・音色・パン](commands/voice.md)) |
| パートごとの長さが違う | ループや終了のタイミングがずれます | すべてのパートを同じ tick の合計にそろえる |

## エラーになる書き方

次のコマンドは、綴りを間違えると、曲が読み込めなくなります。「何も起きない」状態を作らないための動作です。

- リズム: `[RK ...]` `[RV ...]` ([リズム](commands/rhythm.md))
- PSG: `[EV ...]` と `psg_env_` ([PSG](commands/psg.md))
- 生レジスタ: `[RZ ...]` `[RP ...]` ([生レジスタ書き込み](commands/register.md))
- PCM チャンネルのコマンドの範囲外の値 ([PCM](commands/pcm.md))
- 範囲外の `CHP` の番号 (`CHP0` / `CHP9`)

エラーにならないのに鳴らないときは、上の表の「何も起きない」書き方を疑ってください。
