# 音量・音色・パン

## 音量

| コマンド | 意味 |
|---|---|
| `v<N>` | 音量を設定 (0〜15。15 が最大。範囲外は丸められる) |
| `v+` | 音量を 1 つ上げる (最大 15) |
| `v-` | 音量を 1 つ下げる (最小 0) |

曲全体の、音源ごとの音量バランスは [曲ヘッダディレクティブ](../headers.md) の `opll_default_vol=` などで変えられます。

## 音色 `@N`

`@N` で音色を選びます (0〜255)。意味は、鳴らす音源で変わります。

| 音源 | `@N` の意味 |
|---|---|
| OPLL | `@0`〜`@15` は内蔵音色。`@16`〜`@31` は、ユーザー音色スロット `N-16` を読み込んで、ユーザー音色として使う。スロットは `custom_patch_00`〜`custom_patch_0F` で定義する |
| OPNA / OPM | `N` はそのまま音色番号。`opna_patch_NN` / `opm_patch_NN` で定義した音色を使う。定義のない番号は、その音源の既定の音色になる |
| PSG | 旋律の音色としては使わない。`psg_noise_timed_channels=` を指定したチャンネルでは、ノイズ周期の指定になる ([PSG](psg.md)) |

## 音色の定義

音色は、コメント行 (`;` で始まる行) で定義します。

### OPLL ユーザー音色 `custom_patch_NN`

16 進のインデックス `00`〜`0F` と、16 進のバイト 8 つ。

```text
; custom_patch_00: 51 61 17 07 50 F1 5C DC
```

### OPNA の 4 オペレータ音色 `opna_patch_NN`

16 進のインデックス `00`〜`FF` と、10 進の数値 38 個 (`ALG FB`、続けて 4 オペレータ分の `AR DR SR RR SL TL KS MUL DT`)。

```text
; opna_patch_01: 7 0 | 31 0 0 15 0 127 0 1 0 | 31 0 0 15 0 127 0 1 0 | 31 0 0 15 0 127 0 1 0 | 31 0 0 15 0 0 0 1 0
```

### OPM (YM2151) の 4 オペレータ音色 `opm_patch_NN`

16 進のインデックス `00`〜`FF` と、10 進の数値 46 個 (`ALG FB`、続けて 4 オペレータ分の `AR DR SR RR SL TL KS MUL DT1 DT2 AME`)。

```text
; opm_patch_01: 7 0 | 31 0 0 15 0 127 0 1 0 0 0 | 31 0 0 15 0 127 0 1 0 0 0 | 31 0 0 15 0 127 0 1 0 0 0 | 31 0 0 15 0 0 0 1 0 3 1
```

- `|` は見やすくするための区切りで、読み込みでは無視されます。数値だけが読まれます。
- 数値の個数が足りない行は、**黙って無視されます**。
- OPNA と OPM の音色は別々のバンクです。同じ番号を、それぞれ別の音色として持てます。
- 音色の TL は、書いた値がそのまま使われます。

| パラメータ | 範囲 |
|---|---|
| `ALG` `FB` | 0〜7 |
| `AR` `DR` `SR` | 0〜31 |
| `RR` `SL` `MUL` | 0〜15 |
| `TL` | 0〜127 |
| `KS` | 0〜3 |
| `DT` (OPNA) | 0〜7 |
| `DT1` (OPM) | 0〜7 |
| `DT2` (OPM) | 0〜3 |
| `AME` (OPM) | 0 / 1 |

範囲外の値は、範囲内に丸められます。

## パン `p0`〜`p3`

FM チャンネルでは、`p<N>` (0〜3) でパンを設定します。

- **OPM (YM2151)**: ステレオ出力に反映されます。
- OPLL・OPNA: コマンドは受け付けますが、音像は変わりません (OPLL にはパンの機能がなく、OPNA は常に左右とも出力します)。
- PCM チャンネルの `p<N>` は、別に効きます ([PCM](pcm.md))。

0〜3 の範囲外は、読み飛ばされます。
