# 生レジスタ書き込み

動作の検証や、実機の曲の再現のためのコマンドです。通常の作曲では使いません。

| コマンド | 意味 |
|---|---|
| `[RZ <レジスタ> <値>]` | OPLL のレジスタへ、生の値を書き込む。レジスタ・値は **16 進数**。書けるのは `16`〜`18` / `26`〜`28` / `36`〜`38` のみ |
| `[RP <fnum> <block>]` | 半音テーブルを使わず、`fnum` と `block` で音程を直接指定して鳴らす。`fnum` は 16 進数で `000`〜`1FF`、`block` は 0〜7 |

!!! warning "リズムのキーは `[RZ]` で書けません"
    リズムのレジスタ `0E` を `[RZ]` で書くことは、意図的に禁止していて、エラーになります。リズムを鳴らすときは `[RK]` を使ってください ([リズム](rhythm.md))。

## 関連する曲ヘッダ

レジスタの書き込みの列を、曲のヘッダで直接指定することもできます ([曲ヘッダディレクティブ](../headers.md))。

- `; opll_seed=` / `; opll_init=`
- `; opll_register_events=`
- `; ay_register_events=`
