# FAQ

## 曲を再生しても音が出ません

- 音声の出力デバイスが接続されているか、Windows の音量がミュートになっていないか確認してください。
- プレイヤーペインで、チャンネルの `M` (Mute) にチェックが入っていないか確認してください。`S` (Solo) にチェックがあると、ほかのチャンネルは消音されます。
- 画面下部に「音声デバイスからサンプル要求がありません」と表示されるときは、出力デバイスを確認してください。

## 音が小さいです

Windows の音量のほか、曲ごとに、音源ごとの音量 (`; opll_default_vol=` など) を変えられます ([曲ヘッダディレクティブ](reference/headers.md))。

## テンポを変えたいのですが、`t120` が効きません

インラインの `t<N>` は何もしません。曲全体は `; tempo=`、曲の途中は `[TB n]` または `[BPM n]` を使ってください ([ループ・テンポ](reference/commands/flow.md))。

## リズム (ドラム) が鳴りません

`[RK b]` は、鳴らす楽器を選ぶだけです。**音符 (`o2 c` など) を置いたところで鳴ります。** 休符では鳴りません ([リズム](reference/commands/rhythm.md))。

## 音符の長さが思った通りになりません

`c4` のように、音符の後ろに音長は書けません。`L4` のように、前に音長を書いてください。`L` は大文字だけで、小文字の `l4` は音長になりません ([音符・休符・オクターブ・音長](reference/commands/notes.md))。

## `>` や `<` でオクターブが変わりません

`o>` と `o<` と書いてください。単独の `>` `<` は読み飛ばされます。

## `e3` や `d12` が、音符として鳴りません

`e` と `d` の直後に数字が続くと、エンベロープ (`E3`)・デチューン (`D12`) として読まれます。音符のデチューンの variant は `e~1` のように `~` を使って書いてください。

## PCM (`CHP1:`) を書いたらエラーになります

サンプルを鳴らす `n<番号>` があるときは、ファイルの先頭に `#pcmfile "名前.PDX"` が必要です。PDX ファイルは、開いている MML と同じフォルダに置いてください ([PCM](reference/commands/pcm.md))。

## OPM と OPNA で同じ音色番号を使えますか

使えます。`opm_patch_01` と `opna_patch_01` は別々のバンクです ([音量・音色・パン](reference/commands/voice.md))。

## 保存していない編集は、再生に反映されますか

再生中に編集すると、少し待ってから、再生位置を保ったまま、編集中の内容に切り替わります。ファイルに保存するには `Ctrl + S` を押してください。

## 更新の通知が出ません

- 画面右上の「更新確認」にチェックが入っているか確認してください。チェックを入れ直すと、その場で確認します。
- 確認は 1 日に 1 回までです。インターネットに接続していないときは、何も表示されません。
- `Program Files` など書き込みのできないフォルダに置いている場合は、更新ボタンを押しても自動では更新できません。[Releases](https://github.com/fuujii256/RetroFMMusicEditor/releases) から新しい zip をダウンロードしてください。

## 更新に失敗しました

ダウンロードしたファイルの SHA-256 や、更新情報の署名が一致しないときは、安全のために更新を中止します。現在の版のまま使えます。しばらくしてからもう一度試すか、[Releases](https://github.com/fuujii256/RetroFMMusicEditor/releases) から手動でダウンロードしてください。

## 更新した版に問題があるので、前の版に戻したい

実行ファイルと同じフォルダに、1 つ前の版が `NEWFMEditor.App.exe.prev` として残っています。エディタを終了して、`NEWFMEditor.App.exe` を別の名前に変えてから、`.prev` の名前を `NEWFMEditor.App.exe` に戻してください。

## 設定を初期化したい

右上の `↺` ボタンで、設定を初期値に戻せます。MML ファイルやフォルダは削除されません ([画面と操作](getting-started/screen.md))。

## 作った曲を、ゲームなどで使えますか

使えます。商用・非商用を問わず無料です。クレジット表記は任意です。詳しくは [利用規約 (EULA)](https://github.com/fuujii256/RetroFMMusicEditor/blob/main/EULA.md) を参照してください。ただし、他の人の曲を、許可なく再現して公開することは禁止されています。

## MML の途中から聴けますか

0.13.18 以降は、MML Editor 内の音符・休符・演奏コマンドをダブルクリックすると、その位置から全パートを同期して再生できます。
未保存の編集内容も反映し、Mute / Solo を維持します。通常のコメントや空行は対象外です。
長い曲の後方へ移動する場合は、「移動中」の表示の間に待ち時間が生じることがあります。
詳しくは [画面と操作](getting-started/screen.md) を参照してください。
