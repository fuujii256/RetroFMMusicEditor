**[しるふぁ工房 お問い合わせページ](https://fuujii256.github.io/sylfa-studio/contact.html)**

GitHub の Issues は受け付けていません。

## 不具合を報告するときは

次の情報を書いていただけると、原因を早く調べられます。

1. **RetroFM-Music Editor のバージョン** (ウィンドウのタイトルバーに表示されます) と、Windows のバージョン
2. **起きたこと** と、本来どうなってほしかったか
3. **再現する手順**。可能であれば、問題が起きる **MML ファイル** (または、問題の部分だけを抜き出したもの)
4. 可能であれば、**画面のスクリーンショット**

うまくいかないときは、先に [FAQ](faq.md) と [間違えやすい書き方](reference/pitfalls.md) もご確認ください。
