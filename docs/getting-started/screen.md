# 画面と操作

RetroFM-Music Editor の画面は、左から **MML Editor** ・ **Resources** ・ **プレイヤー** の 3 つのペインに分かれています。

| ペイン | 役割 |
|---|---|
| MML Editor (左) | MML のテキストエディタ。演奏中の位置がハイライトされます |
| Resources (中央) | MML ファイルを含むフォルダの一覧。ファイルを選ぶとエディタで開きます |
| プレイヤー (右) | チャンネルごとの発音表示、レベルメーター、Solo / Mute |

MML Editor の見出しの左にある **`<`** ・ **`>`** ボタンで、表示するペインの数を変えられます。

| ペインの数 | 表示 |
|---|---|
| 1 | MML Editor だけ |
| 2 | MML Editor とプレイヤー |
| 3 | MML Editor ・ Resources ・ プレイヤー |

`>` を押すとペインが増え、`<` を押すと減ります。ペインの数は次回起動時に復元されます。ペインの境界をドラッグすると、ペインの幅を変えられます。幅は、ペインの数を変えても覚えています。

## ファイルを開く・作る

- Resources ペインの「フォルダー」から、MML を置いたフォルダを開きます。開いたフォルダと、展開していたフォルダは、次回起動時に復元されます。
- ファイルをクリックすると、エディタで開きます。
- 開いているファイルをダブルクリックすると、エディタの内容をその場で再生します。フォルダをダブルクリックしたときは、展開・折りたたみになります。
- 「＋」ボタンで、開いているフォルダの中に新しい `.mml` ファイルを作ります。すでにあるファイル名は上書きされません。
- 新しいファイルには、最初から、曲ヘッダの既定値 (`; chip=all`、`; tempo=75`、`; default_variant=2`、音源ごとの音量) と、OPM・OPLL・OPNA・SCC の 4 パートのドレミが書かれています。そのまま再生できるので、書き換えながら試せます。
- `Ctrl + S` で保存します。

## コマンドの説明

Resources ペインの下に、**エディタのカーソルがあるコマンドの説明** (名前・書式・説明) が表示されます。カーソルが `;` のコメント (曲ヘッダ) にあるときは、そのヘッダの説明が出ます。

- カーソルが音符の `c~1` にあれば音符と variant の説明、`[LOOP 2]` にあればループの説明、というように、1 行に多数のコマンドがあっても、カーソルの位置のコマンドが引かれます。
- 説明の内容は、[コマンドリファレンス](../reference/index.md) と同じです。
- このパネルは Resources ペインの中にあるので、ペインの数が 3 のときだけ見えます。

## 再生する

- 画面下部の `▶` (再生)・`Ⅱ` (一時停止)・`■` (停止) で再生を操作します。
- 画面下部のスライダーで再生位置を動かせます。つまみをドラッグしている間は一時停止し、離すとその位置から再生を続けます。トラックをクリックすると、その位置へ移動します。
- 曲が無限にループする場合は、基本的に先頭から 60 秒までをスライダーの範囲にします。MML テキストからそれより後へ移動した場合は、移動先を含む範囲まで広がります。
- 再生中に MML を編集すると、少し待ってから、再生位置を保ったまま新しい内容に切り替わります。

## MML の途中から再生する

MML Editor 内の **音符・休符・演奏コマンドをダブルクリック** すると、その開始位置から全パートを同期して再生します。
停止中・再生中・一時停止中に使え、未保存の編集内容も反映されます。Mute / Solo は維持されます。

- ループ内の同じ文字位置は、最初に演奏される時刻を使います。
- 通常のコメント、空行、演奏されない位置では再生を始めません。
- 空白やチャンネル見出しは同じ行の次のイベントへ、行末の空白は直前のイベントへ対応します。
- 移動の準備中は「移動中」と表示します。長い曲の後方へ移動すると、準備に時間がかかることがあります。
- 準備中に編集、停止、ファイル変更、別の位置のダブルクリックを行うと、古い移動要求を取り消します。

## プレイヤーの見方

- チャンネルごとに、発音中の音の高さ (鍵盤表示)、音の大きさ (レベルメーター)、音名を表示します。リズムは、BD / SD / HH / CY / TM / RI の発音パッドで表示します。
- **音源ごとに色分け** します。OPLL は橙、OPM は緑、OPNA は青、PCM は桃です。エディタの演奏中ハイライトも同じ色になるので、どの音源がどの部分を鳴らしているかが分かります。
- チャンネルをクリックすると、そのチャンネルが今演奏している MML の位置へカーソルが移り、その位置が画面の中央に来るようにスクロールします。
- `S` (Solo) は複数のチャンネルに同時にチェックできます。Solo を付けたチャンネルがあるあいだは、ほかのチャンネルが消音されます。Solo を外すと、元の Mute の状態に戻ります。
- `M` (Mute) で、そのチャンネルだけを消音します。
- プレイヤーペインを広げる (660 ピクセル程度以上) と、鍵盤が 8 オクターブ表示に広がります。

## キー操作

| キー | 動作 |
|---|---|
| `Ctrl + S` | 保存 |
| `Ctrl + +` / テンキーの `+` | 画面とエディタの文字を大きくする (8 〜 32) |
| `Ctrl + -` / テンキーの `-` | 画面とエディタの文字を小さくする (8 〜 32) |
| `Alt + Enter` | 全画面の切り替え (枠なしの最大化) |

## ウィンドウ

ウィンドウは、サイズ変更と最大化ができます。最後に使ったサイズ (と最大化の状態) は、次回起動時に復元されます。初めて起動したときは、1920 × 1080 ピクセルで開きます。

右上の「更新確認」は、起動時に新しい版を確認するかどうかを切り替えます。新しい版があると「更新 x.y.z」ボタンが表示されます ([インストール](install.md))。

右上の `↺` ボタンは、確認のあとで、フォルダ・編集中のファイル・表示・文字サイズなど、エディタの保存状態をすべて初期値に戻します。MML ファイルやフォルダは削除されません。
