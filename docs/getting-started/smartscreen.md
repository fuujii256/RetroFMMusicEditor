# SmartScreen の警告が出たとき

RetroFM-Music Editor の実行ファイルにはコード署名をしていません。そのため、インターネットからダウンロードしたファイルを初めて起動するときに、Windows の警告 (SmartScreen) が表示されることがあります。

ダウンロードしたファイルが本物かどうかは、[ハッシュ値の確認](#hash) で確かめられます。

## 展開する前に「ブロックの解除」をする (おすすめ) {#unblock}

zip を展開する **前に** 次の操作をすると、展開したファイルで警告が出なくなります。

1. ダウンロードした zip ファイルを右クリックし、「プロパティ」を選びます。
2. 「全般」タブのいちばん下にある「セキュリティ」の **「許可する」** にチェックを入れます。
3. 「OK」を押します。
4. zip を展開します。

!!! tip
    「許可する」の項目が表示されない場合は、すでにブロックが解除されています。そのまま展開してください。

## 警告が表示されてしまったとき {#run-anyway}

「Windows によって PC が保護されました」という画面が表示された場合は、次の操作で起動できます。

1. 画面の **「詳細情報」** を押します。
2. 表示された **「実行」** ボタンを押します。

## スマート アプリ コントロールが有効な場合 {#smart-app-control}

Windows 11 の「スマート アプリ コントロール」が有効になっている PC では、署名のないアプリは警告なしにブロックされ、上の「実行」ボタンも表示されません。

!!! warning "既知の制限"
    スマート アプリ コントロールが有効な PC では、現在 RetroFM-Music Editor を起動できません。起動するには、Windows セキュリティの「アプリとブラウザー コントロール」→「スマート アプリ コントロール」を **オフ** にする必要があります。一度オフにすると、Windows を再インストールするまで元に戻せない場合があります。オフにするかどうかは、ご自身で判断してください。

## 2 回目以降の更新について

エディタの更新機能でダウンロードした更新では、通常この警告は表示されません。警告が出るのは、最初にブラウザで zip をダウンロードしたときだけです。

## ハッシュ値の確認 {#hash}

[Releases](https://github.com/fuujii256/RetroFMMusicEditor/releases) の各ページに、配布ファイルの SHA-256 ハッシュ値を載せています。PowerShell で次のコマンドを実行し、表示された値が一致するか確認してください。

```powershell
Get-FileHash .\RetroFMMusicEditor_0.13.9.zip -Algorithm SHA256
```
