# インストール

!!! info "最新版"
    最新版は [RetroFM-Music Editor 0.13.15](https://github.com/fuujii256/RetroFMMusicEditor/releases/tag/v0.13.15) です (ベータ版)。

## 動作環境

- Windows 10 / 11 (64 ビット)
- 音声の出力デバイス

## インストールの手順

1. [Releases](https://github.com/fuujii256/RetroFMMusicEditor/releases) から `RetroFMMusicEditor_<バージョン>.zip` をダウンロードします (例: `RetroFMMusicEditor_0.13.15.zip`)。
2. **展開する前に**、zip を右クリック →「プロパティ」→「セキュリティ: 許可する」にチェック →「OK」を押します。詳しくは [SmartScreen の警告が出たとき](smartscreen.md) を参照してください。
3. 好きな場所に展開します。
4. 展開したフォルダの `NEWFMEditor.App.exe` をダブルクリックすると、エディタが起動します。

zip には、エディタ本体 (`NEWFMEditor.App.exe`)、利用規約 (`EULA.md`)、第三者ソフトウェアのライセンス (`THIRD-PARTY-NOTICES` フォルダ) が入っています。.NET を同梱しているので、別途インストールする必要はありません。

!!! note "実行ファイルの名前について"
    実行ファイルの名前は `NEWFMEditor.App.exe` ですが、ウィンドウに表示される名前は「RetroFM-Music Editor」です。

## 更新

0.13.12 以降は、エディタの中から更新できます。

1. 起動時に、新しい版があるかを確認します (1 日に 1 回まで)。新しい版があると、画面右上に **「更新 x.y.z」** ボタンが表示されます。
2. ボタンを押すと、更新の内容が表示されます。「はい」を押すと、新しい版をダウンロードし、署名と SHA-256 を検証してから、エディタを再起動して更新します。編集中の内容は、先に保存してください。
3. 設定 (ウィンドウサイズ、表示、開いていたフォルダなど) は、そのまま引き継がれます。自分で作った MML ファイルは、上書きされません。

右上の「更新確認」のチェックを外すと、起動時の確認をしなくなります。チェックを入れ直すと、その場で確認します。

更新した版で不具合が出たときは、実行ファイルと同じフォルダにある `NEWFMEditor.App.exe.prev` (1 つ前の版) の名前を元に戻すと、前の版に戻せます。

!!! note "0.13.11 以前をお使いの場合"
    0.13.11 以前には、公開された更新の仕組みがありません。新しい zip を別のフォルダに展開してください。

!!! note "自動で更新できない場合"
    `Program Files` など、書き込みのできないフォルダに置いている場合は、自動で更新できません。その場合は、[Releases](https://github.com/fuujii256/RetroFMMusicEditor/releases) から新しい zip をダウンロードして、別のフォルダに展開してください。

## アンインストール

展開したフォルダを削除してください。エディタの設定は `%LOCALAPPDATA%\NEWFMEditor` にあるので、不要であればこのフォルダも削除してください。
自分で作った MML ファイルは、削除されません。
