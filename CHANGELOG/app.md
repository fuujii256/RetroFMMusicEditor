# 変更履歴 (RetroFM-Music Editor)

## 0.13.11 (2026-10-05)

- 文字の表示を、VNStudio の実際の表示に合わせました。
    - UI の文字は、システム既定のフォント (日本語 Windows では Yu Gothic UI) の 12、黒にしました。MML エディタは Consolas の 14 です。
    - 見出しは、MML Editor が 18、Resources と右側のペインが 16 の太字です。
    - 文字サイズの設定は、1 度だけ 12 に戻ります。以後は `Ctrl +` / `Ctrl -` で変えた値が保存されます。

## 0.13.10 (2026-10-05)

- 画面の構成を、VNStudio に合わせて変更しました。
    - 左から、MML Editor ・ Resources (ファイル一覧) ・ プレイヤー (チャンネル表示) の順に並びます。
    - MML Editor の見出しの左に `<` `>` ボタンを付けました。表示するペインの数 (1 〜 3) を変えられます。上部の File / MML / Player の切り替えボタンは廃止しました。
    - 配色を、VNStudio と同じ落ち着いた空色にしました。文字の基準サイズを 14 にして、ペインの見出しを 18 の太字にしました (文字サイズの設定は、1 度だけ 14 に戻ります)。
    - プレイヤーペインが十分に広いときだけ、鍵盤が 8 オクターブ表示になります。
- 異常終了のログを、上書きせずに追記するようにしました。

## 0.13.9 (2026-10-05)

- 新しい版の通知と、更新の機能を追加しました。
    - 起動時に (1 日に 1 回まで) 新しい版を確認し、あれば画面右上に「更新 x.y.z」ボタンを表示します。
    - ボタンを押すと、ダウンロードして、署名と SHA-256 を検証したうえで、エディタを再起動して更新します。
    - 1 つ前の実行ファイルを `NEWFMEditor.App.exe.prev` として 1 世代残します。自分で作った `MML` フォルダのファイルは上書きしません。
    - 画面右上の「更新確認」で、起動時の確認をオフにできます。
- 0.13.8 以前には更新の機能がないので、0.13.9 以降には、zip を手動でダウンロードして移行してください (0.13.9 と 0.13.10 は一般には公開せず、0.13.11 から公開します)。

## 0.13.8 (2026-10-05)

- プレイヤーペインの「チャンネル」の見出しと、音源の色の凡例 (OPLL / OPM / OPNA / PCM) を、チャンネル一覧をスクロールしても消えないように、上部に固定しました。

## 0.13.7 (2026-10-05)

- ウィンドウのサイズ変更と最大化ができるようになりました。
    - 最小サイズは 820 × 480 です。初めて起動したときは、これまでどおり 1920 × 1080 ピクセルで開きます。
    - 最後に使ったサイズと、最大化の状態を、次回起動時に復元します。
    - `Alt + Enter` の全画面を解除すると、全画面にする前のサイズに戻ります。
- チャンネルの表示と、演奏中の MML のハイライトを、音源ごとに色分けしました (OPLL 橙・OPM 緑・OPNA 青・PCM 桃)。
- プレイヤーのチャンネルをクリックすると、そのチャンネルが今演奏している MML の位置へカーソルを移し、画面の中央に表示するようにしました。
- 再生音量を、約 14 dB 大きくしました。ピークは -1 dBFS に抑えるリミッターを付けているので、音は割れません。

## 0.13.6 (2026-10-04)

- 無音の PCM トラック (`CHP1: v13` のように、サンプルを鳴らす音符がないもの) を持つ曲を、読み込めるようにしました。`#pcmfile` が必要なのは、サンプルを鳴らす音符があるときだけです。

## 0.13.5 (2026-08-09)

- MXDRV の「直後の 1 音だけをつなぐ `&`」の扱いを修正しました。
- OPM (YM2151) を、ネイティブに演奏できるようになりました。MXDRV の `A`〜`H` が、OPM の 0〜7 番に直接割り当てられます。
- PCM (PDX / MSM6258) を演奏できるようになりました。`CHP1:`〜`CHP8:` で、PCM チャンネルを書けます。
- `L<分母>` で、長さを音楽的な単位 (`L4` `L8.` など) で指定できるようになりました。
- 曲ごとに、音源ごとの音量を指定できるようになりました (`; opll_default_vol=` など)。
- 再生中の編集を、再生位置を保ったまま反映できるようになりました。
- `; chip=all` で、OPM・OPLL・OPNA を同時に演奏できるようになりました。

## 0.13.4 (2026-08-05)

- YM2608 (OPNA) の FM を、高精度のエミュレータ (ymfm) に切り替えました。
- MXDRV の曲の再生精度を改善しました。

## 0.13.2 (2026-07-30)
